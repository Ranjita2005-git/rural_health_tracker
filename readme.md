🚑 Nivaran — Rural Healthcare, Within Reach

Nivaran is a smart rural healthcare platform (offline based) built to bridge the gap between villagers and accessible healthcare. It enables users to describe symptoms through voice, receive preliminary triage guidance, discover nearby healthcare facilities, check doctor availability, and digitally create and track referrals.

From “Where should I go?” to “I know where to go.”

🔹 Voice-based & multilingual
🔹 Location-aware healthcare discovery
🔹 Doctor availability & digital referrals
🔹 Connects Villagers • ASHA Workers • PHCs
🔹 Designed for rural & low-connectivity environments

Built with: React.js • TypeScript • FastAPI • Python • PostgreSQL • PostGIS • Web Speech API • JWT • Google Maps

Backend port - http://localhost:8000/
Frontend port - http://localhost:8443/
